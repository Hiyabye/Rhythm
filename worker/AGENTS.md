# Feed Worker

Area instructions for `worker/`. The root `AGENTS.md` (project-wide rules) applies too.

- `worker/` (#175): the read-only Cloudflare Worker (TypeScript + wrangler, its own npm package with its own `package-lock.json`; the root `npm ci` never installs it) that serves the feed of `docs/FEED.md` from the R2 binding `FEED` (`rhythm-feed`) under `PREFIX` (`feed/`, `wrangler.toml`). `src/index.ts` answers only `GET`/`HEAD` (else 405), rate-limits per `cf-connecting-ip` through the `LIMITER` binding (60/60 s, per location and approximate; 429 with `retry-after`), serves only `manifest.json`, `manifest.json.sig` and one content-named `.jsonl.zst`/`.vec` under `segments/` or `snapshots/` (anything else 404, so test or state prefixes are never exposed), and passes R2 only `If-None-Match` (or `If-Modified-Since`) for 304s; headers per kind are in FEED.md. No CORS, logging, secrets or write path; telemetry is off (`send_metrics = false`). Tests (`test/index.test.mjs`) run the compiled handler under `node --test` with a fake R2 bucket and limiter: `cd worker && npm ci --ignore-scripts && npm test` (`tsc` then the tests; `npm run check` type-checks only). `npx wrangler deploy --dry-run --outdir <scratch>` bundles and lists the bindings offline. Deploying (`npm run deploy`, run from `main`) changes remote state and needs approval and an Account API token with Workers Scripts: Edit and Workers R2 Storage: Read (wrangler checks the bucket; Keychain `rhythm-cf-worker-deploy`, account = account ID, read into `CLOUDFLARE_API_TOKEN`/`CLOUDFLARE_ACCOUNT_ID`, never printed). `wrangler delete` also lists KV namespaces, which that token can't; delete a test Worker through the `workers/scripts` API instead. Observed 2026-11-18 (#175) on the Free plan: the rate-limit binding deploys, but it is loose (about 375 requests passed within a minute before the first 429); 200/304/404/405/HEAD and segment hashes matched FEED.md through a separate `rhythm-feed-test` Worker on a test prefix. A live check deploys such a separate Worker (`--name rhythm-feed-test --var PREFIX:test-feed/`), never the production name with another prefix.
