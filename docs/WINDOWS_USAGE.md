# Rhythm Windows 사용 안내

지원 대상은 Windows 11 x64입니다. 이 Windows 이식판의 실제 시험 범위와 미검증 조건은 [검증 기록](WINDOWS_VALIDATION.md)을 함께 확인하세요.

## 설치

1. 설치 파일과 함께 제공된 SHA-256 값을 확인합니다.
2. 현재 Windows 사용자 계정으로 설치 파일을 실행합니다. 기본 프로그램 위치는 `%LOCALAPPDATA%\Programs\Rhythm`입니다.
3. WebView2 Runtime이 없으면 설치 프로그램이 Microsoft의 설치 도구를 내려받으므로 인터넷 연결이 필요합니다. 이미 설치되어 있으면 기존 Runtime을 사용합니다.
4. 시작 메뉴에서 Rhythm을 엽니다. 공지와 설정은 프로그램 폴더와 별도로 `%LOCALAPPDATA%\app.rhythm.windows`에 저장합니다. 모델의 기본 위치도 이 데이터 폴더 아래이며, 새 모델의 설치 위치는 AI 설정에서 따로 선택할 수 있습니다.

이 배포는 정식 코드 서명을 포함하지 않습니다. Windows가 신뢰 확인 또는 경고를 표시할 수 있습니다. 설치 파일의 출처와 해시를 확인하고, 경고에 대한 판단은 사용자가 직접 합니다.

## 공지와 AI

정보원을 선택한 뒤 공지를 수집합니다. 수집 범위가 제한되거나 첨부 자료를 받지 못한 경우 화면의 상태를 확인하세요. 저장된 본문과 내려받은 자료는 로컬에서 읽을 수 있지만, 외부 링크나 저장하지 못한 자료까지 오프라인으로 제공하는 것은 아닙니다.

AI 모델 가중치는 설치 파일에 포함하지 않습니다. AI 설정에서 모델을 내려받거나 지원되는 파일을 등록합니다. 2B·4B의 Windows CPU 검증 상태는 모델 설명과 검증 기록에 구분합니다. 모델을 다운로드한 사실만으로 분석 품질이나 속도를 보장하지 않습니다.

0.9.4부터 **설정 → AI 모델 → 모델 설치 폴더 → 설치 폴더 선택**으로 새 모델의 위치를 바꿀 수 있습니다. 현재 폴더와 남은 공간을 확인한 뒤 사용할 폴더를 선택하세요. 쓰기 권한이 없거나 링크 경로인 폴더는 거부하며, 저장에 실패하면 기존 설정을 유지합니다. 이미 설치한 모델과 중단한 다운로드는 이동하지 않고 원래 위치에서 사용하거나 이어받습니다. **기본 위치로 되돌리기**도 기존 파일을 이동하거나 삭제하지 않습니다. 모델마다 실제 저장 위치를 목록에서 확인할 수 있습니다. 진행 중인 AI 작업을 완료하거나 취소한 뒤 위치를 바꾸세요. 이 PC의 별도 시험용 앱에서 실제 폴더 선택·취소·재실행 후 유지·기본 위치 복귀를 확인했습니다. 최종 설치본과 다른 PC에서의 조작은 아직 미검증입니다.

기존 모델 폴더에 접근할 수 없거나 다른 위치에 다시 설치하려면 **내 모델 → 모델 삭제 → 파일을 남기고 목록에서 제거**를 선택하세요. 원본 파일은 그대로 두고 등록만 지우므로, 새 설치 폴더를 선택한 뒤 다시 설치할 수 있습니다.

AI 설정의 **AI 실행 장치**에서 자동·CPU·NVIDIA GPU를 선택할 수 있습니다. 자동은 GPU 사용을 먼저 시도하고 사용할 수 없으면 CPU로 전환합니다. GPU를 직접 지정한 경우 실패 이유를 표시합니다. 선택한 설정과 실제 분석에 사용한 장치는 다를 수 있으므로 화면의 실행 상태를 확인하세요. 설정을 바꾸면 불러온 모델을 해제하고 다음 분석부터 적용하며, 기존 분석 결과는 보존합니다.

GPU 워커는 Vulkan을 사용하며 GTX 10·16과 RTX 20·30·40·50 시리즈를 지원 대상으로 합니다. 모든 기종의 실제 시험을 완료한 것은 아닙니다. NVIDIA 그래픽 드라이버가 필요한 Vulkan 기능을 제공해야 하며, 메모리가 부족하면 모델을 불러오지 못할 수 있습니다. 개발용 Vulkan SDK는 설치본 사용에 필요하지 않습니다. 자세한 조건과 기종별 시험 범위는 [Windows GPU 안내](WINDOWS_GPU.md)를 확인하세요.

## 백그라운드 실행과 알림

자동 시작, 숨김 시작, 창 닫기 후 백그라운드 유지, 예약 수집과 알림은 기본적으로 꺼져 있습니다. 필요한 항목만 설정에서 켜세요. 예약 수집은 Rhythm이 실행 중일 때 동작합니다. 창 닫기 후 백그라운드 유지를 켠 경우 완전히 종료하려면 트레이 메뉴의 **Rhythm 종료**를 선택합니다.

설정의 백그라운드 항목에서 알림 상태가 **연결 확인 필요**로 나오면 **시험 알림으로 연결 확인**을 직접 눌러 시험할 수 있습니다. 시험 알림에는 공지 내용이 들어가지 않으며, 운영체제에 표시를 요청합니다. 요청이 성공해도 화면에 실제로 나타났다는 뜻은 아닙니다. Windows 알림이 꺼져 있다고 확인되면 Windows 설정에서 확인한 뒤 상태를 새로고침하세요. 연결 상태가 허용으로 확인된 다음 앱의 알림 스위치를 켤 수 있습니다. 시험을 누르지 않은 상태 조회는 알림을 보내지 않습니다.

알림은 설치된 프로그램의 전용 링크와 로컬 일회성 토큰을 사용합니다. 설치되지 않은 복사본에서는 알림 연결을 사용할 수 없습니다. 토큰은 7일 뒤 만료되며, 연결된 알림 기록이 정리되었거나 백업을 복원한 경우 예전 Windows 알림을 눌러도 공지가 열리지 않을 수 있습니다. 앱의 공지 보관함에서 직접 찾을 수 있습니다.

## 백업과 복원

백업 파일에는 데이터베이스와 내려받은 자료가 포함되고 모델 가중치는 제외됩니다. 다른 PC에서 복원한 뒤에는 필요한 모델을 다시 설치하거나 등록하세요. 복원 작업 영역은 앱의 로컬 고정 NTFS 데이터 폴더이며, 네트워크·이동식 드라이브나 리파스 경로는 지원하지 않습니다.

백업을 복원하면 새 모델의 설치 폴더 설정은 기본값으로 돌아갑니다. 사용자 지정 폴더에 설치했던 모델은 사용할 수 없는 외부 파일 참조로 바뀌므로, 필요한 원본을 다시 등록하거나 모델을 다시 설치하세요. 이 처리에서 기존 모델 파일을 삭제하거나 다른 폴더로 옮기지 않습니다.

복원은 기존 파일을 보존한 뒤 재실행 과정에서 완료합니다. 복원 상태를 판별할 수 없다는 오류가 나오면 남은 파일을 임의로 삭제하지 마세요. 복원 프로세스 강제 종료 시험과 실제 전원 장애는 다르며, 모든 저장장치의 갑작스러운 전원 손실까지 보장하지 않습니다.

## 수동 업데이트와 제거

앱 내 자동 업데이트는 비활성화되어 있습니다. 새 설치 파일의 해시를 확인하고 Rhythm을 트레이 메뉴까지 포함해 완전히 종료한 뒤, 기존에 설치했던 Windows 사용자 계정으로 새 설치 파일을 실행합니다. 공지와 설정, 모델은 프로그램과 별도 위치에 보관합니다. 중요한 자료는 업데이트 전에 별도로 백업해 두세요. 실제 갱신 시험 결과는 검증 기록을 확인하세요.

Windows의 설치된 앱 목록에서 Rhythm을 제거할 수 있습니다. 제거 프로그램은 공지와 설정, 내려받은 자료와 모델을 항상 보존합니다. 사용자 데이터 삭제 기능은 제공하지 않습니다. 실제 제거와 데이터 보존 시험의 범위는 검증 기록을 확인하세요.
